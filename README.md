## VS Code Live Server로 실행

`index.html`을 브라우저에서 바로 확인하려면 VS Code의 **Live Server** 익스텐션을 사용해야 한다.

### Live Server 익스텐션 설치

1. extensions 검색창에 `Live Server` 입력
2. **Ritwick Dey**가 만든 **Live Server**를 **Install**
3. `index.html` 파일 **우클릭**
4. **Open with Live Server** 클릭
